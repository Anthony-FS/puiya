# @puiya/ui

Design tokens (colours, spacing, type scale) shared by NativeWind on mobile and Tailwind on web.
Created in its own PR alongside the first mobile screen, so the tokens are designed against a
real screen rather than in the abstract.

Constraints from [CLAUDE.md](../../CLAUDE.md): body text ≥ 18px, tap targets ≥ 48dp,
high contrast, Thai-capable fonts (Sarabun or Noto Sans Thai).
